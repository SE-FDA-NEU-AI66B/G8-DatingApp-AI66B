# Sprint 4 repository requirements

## 4. Required state of your repository

| Item                                                | Minimum                                                |
| --------------------------------------------------- | ------------------------------------------------------ |
| Merged pull requests in Sprint 4                    | **4**, each reviewed by someone else                   |
| Issues closed in Sprint 4                           | **5**                                                  |
| Per member: merged PR · review given · issue closed | **At least 1 each**                                    |
| Per member: tests written                           | **At least 1 test in `tests/` written by each member** |
| `docs/SETUP.md` — still works on a new machine      | Includes how to run the tests                          |
| `[Chore] Refine backlog for Sprint 4` → PO          | **1**, closed                                          |
| `[Chore] Sprint 4 wrap-up` → SM                     | **1**, closed                                          |
| `docs/sprint-log.md` — Sprint 4 section             | Committed · completed · velocity                       |
| Scrum Master                                        | A **different person** from Sprint 3, named in README  |
| Optional — `docs/retro.md`, Sprint 4 retrospective  | One action, one owner                                  |

### Minimum bar

1. PDF submitted by the deadline with the full cover block.
2. `docs/testing.md` has all four sections, in order.
3. `tests/` on `main` contains tests, and at least one passes.
4. `docs/sprint-log.md` records committed, completed, and velocity for Sprint 4.
5. The project board opens from the link you submitted.
6. `docs/SETUP.md` is still on `main`.
