# NEUDating

A dating app for NEU students, built with Rust, Leptos, and PostgreSQL.

## Run locally

Follow [docs/SETUP.md](docs/SETUP.md) to configure Microsoft sign-in and the
database. Then start the app:

```bash
cargo leptos watch
```

Open <http://localhost:3100>.
